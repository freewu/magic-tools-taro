技术特性

从 uni-app x 版 magic-tools-lite 迁移重构而来，业务逻辑与交互保持一致。

🔒

纯本地计算

所有工具都在设备上算，不请求接口、不上传输入内容，号码类数据也只在本机解析。

📴

断网可用

没有网络依赖，小程序 / App 离线打开即可用；偏好设置与置顶存在本地存储里。

🧩

一套代码多端

Taro 4 + React 18 + TypeScript，编译到 7 个小程序平台、H5 与 Android。

⚡

打开就能算

每个工具一屏完成输入与结果，不做多级跳转；换算结果点击即复制。
